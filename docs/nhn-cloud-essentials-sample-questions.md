# NHN Cloud Certified - Essentials 공식 샘플 문제

> 출처: NHN Cloud 공식 자격증 샘플 문제 페이지 (https://rlutbig4t.toastcdn.net/static/exam-sample/v1/essentials.html).
> 본 프로젝트의 `cert-explainer` subagent가 톤·구조·난이도의 기준으로 참조하는 baseline 문서.

본 문서의 문제는 **출제 톤·표현·구조의 reference**로 사용한다. 본 프로젝트의 `data/questions.json` 콘텐츠 보강·신규 생성 시 이 톤에 맞춘다.

---

## 1. 클라우드 모델 — IaaS 정의

가상 머신, 네트워크, 스토리지와 같은 리소스의 클라우드 유형은 무엇인가요?

- SaaS
- PaaS
- DaaS
- **IaaS** ← 정답

## 2. 책임 공유 모델 — CSP의 책임

책임 공유 모델을 기반으로 클라우드 서비스 공급자(CSP)가 책임져야 하는 내용으로 맞는 것은 무엇인가요?

- 웹 서비스 배포 자동화 처리
- 인스턴스 운영체제 업데이트
- 인스턴스 접속 계정 관리
- **IDC의 물리적 보안 관리** ← 정답

## 3. 글로벌 서비스 식별

NHN Cloud에서 제공하는 서비스 중 글로벌 서비스로 맞지 않는 것은 무엇인가요?

- DNS Plus
- **VPC** ← 정답 (글로벌 서비스 아님 — 리전 단위)
- CDN
- Cloud Trail

## 4. Floating IP 특성

다음 중 NHN Cloud Floating IP 서비스 설명으로 맞는 것은 무엇인가요?

- 플로팅 IP는 인스턴스에만 연결하여 사용할 수 있다.
- **인터넷에서 인스턴스를 직접 액세스하기 위해 필요한 기능이다.** ← 정답
- 특정 리소스에 연결하여 사용했던 플로팅 IP는 다른 리소스에 연결할 수 없다.
- 유동적인 주소로 시간이 지나면 변경된다.

## 5. 보안 그룹 vs 네트워크 ACL

NHN Cloud의 보안그룹과 네트워크 ACL에 대한 설명으로 맞는 것은 무엇인가요?

- 보안 그룹과 네트워크 ACL을 같이 사용할 경우 보안 그룹 설정이 먼저 적용된다.
- **네트워크 ACL은 허용과 차단 설정으로 접근을 제어한다.** ← 정답
- 외부 원격지에서 플로팅 IP 설정된 인스턴스로 ping 테스트를 하기 위해 네트워크 ACL에서 ICMP 허용 규칙을 적용하면 보안 그룹에서도 해당 규칙이 적용된다.
- 보안 그룹의 네트워크 접근 제어 규칙은 사용자가 설정한 priority order 번호 순서에 따라 적용되기 때문에 설정 시 고려해야 한다.

## 6. NAS 서비스 — 부정형 (NOT)

NHN Cloud NAS 서비스에 대한 설명으로 맞지 **않은** 것은 무엇인가요?

- 하나 이상의 인스턴스에 마운트하여 사용할 수 있다.
- 별도의 포맷 작업이 필요하지 않다.
- NAS의 스냅숏을 사용하면 특정 시점의 데이터로 복원할 수 있다.
- **NFS 파일 시스템만 지원한다.** ← 정답 (사실은 NFS 외 지원도 있음 — 다른 보기들은 맞는 설명)

## 7. 크레딧 정책 — 부정형 (NOT)

다음 중 NHN Cloud의 크레딧 설명으로 **틀린** 것은 무엇인가요?

- 현금 1원과 동일하게 사용된다.
- 크레딧을 보유하고 있다면 선차감 후 결제가 진행된다.
- 보유 크레딧보다 많은 금액이 청구된 경우, 차액은 등록된 결제수단으로 청구된다.
- **가입축하 크레딧은 유효기간 이내에 연장 신청하면 연장이 가능하다.** ← 정답 (가입축하 크레딧은 연장 불가)

## 8. 요금 발생 케이스

다음 중 NHN Cloud 서비스 이용시 요금이 발생하지 **않는** 경우는 무엇인가요?

- 인스턴스를 중지한 경우 (블록 스토리지 비용 발생)
- 플로팅 IP 생성 후 인스턴스에 할당하지 않는 경우 (미할당 상태 비용 발생)
- 이미지 생성 후 사용하지 않는 경우 (저장 비용 발생)
- **플로팅 IP를 할당 해제 후 삭제한 경우** ← 정답 (삭제하면 비용 발생 안 함)

## 톤·구조 관찰 노트 (cert-explainer 참고용)

1. **질문 종결 어미**: "~ 무엇인가요?" (정중·중립)
2. **부정형 문제**: "맞지 않은 / 틀린 / 발생하지 않는" 등 부정 명시는 **굵게** 또는 명확히
3. **보기 톤**: 단정문, 간결, 한 줄 위주. 한 보기 = 한 사실.
4. **선택지 길이**: 1~2줄, 5번처럼 긴 보기는 multi-clause로 정밀
5. **도메인 분포**: 1번(개념), 2번(개념/보안), 3~6번(서비스 특징·활용), 7~8번(결제·요금) — 시험 안내서 비율과 일치
6. **단일 선택형**: 4지선다 / 다중 선택형은 5지선다 (이 샘플엔 없지만 시험 안내서에 명시)

본 톤을 따른다는 것은 시험 안내서의 "**사용자 가이드 내용에 존재하는 내용으로만 출제**" 원칙과 합쳐, **명확한 사실 인용 + 정중 중립체 + 간결**.
