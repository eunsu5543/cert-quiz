# NHN Cloud Certified - Essentials 시험 안내서

> 출처: NHN Cloud 공식 자격증 안내. `data/questions.json`의 콘텐츠와 `cert-explainer` subagent가 참조하는 시험 범위 기준 문서.

## 소개

클라우드 컴퓨팅의 세계로 첫발을 내딛을 수 있는 초급 과정으로, 실무 경험이 없어도 도전할 수 있습니다. 클라우드 컴퓨팅의 기본 원리와 기술에 대한 포괄적인 이해를 제공하는 초급 과정이며, NHN Cloud 서비스에 대한 기본적인 이해도를 검증할 수 있는 자격증입니다.

IT 분야의 초보자나 클라우드 기술에 관심이 있는 사람들에게 이상적인 시작점.

## 시험 유형

- **출제 문항 수**: 총 60문제
  - **단일 선택형**: 4보기 중 1개 정답 (오답 3개)
  - **다중 선택형**: 5보기 중 2개 이상 정답
- **합격 점수**: 1000점 만점 중 **700점 이상**

## 시험 콘텐츠 (출제 비율)

| 도메인 | 세부 영역 | 비율 |
|---|---|---|
| **클라우드 개념 및 보안** | 클라우드 컴퓨팅 개념·특징, 책임공유 모델, 일반적인 클라우드 보안 개념 | **15%** |
| **NHN Cloud 서비스 특징** | NHN Cloud의 일반적인 서비스 특징(정책, 리소스 제한), 각 상품에 대한 일반적인 설명 | **34%** |
| **NHN Cloud 서비스 활용 기술** | NHN Cloud 상품 활용 기술 영역, 조직/프로젝트 개념 활용 | **40%** |
| **결제 및 요금** | 클라우드 컴퓨팅 요금제 이해, NHN Cloud 요금 정책 및 크레딧 | **11%** |

## 시험 준비 자료

- **NHN Cloud Training: Cloud Essentials** (공인 교육 과정) — 교육 과정 및 교재에서 다루는 내용 기반으로 문제 출제. 수강 권장.
- **NHN Cloud 사용자 가이드** — **모든 자격증 출제 문제는 사용자 가이드 내용에 존재하는 내용으로만 출제됨**. 따라서 해설 작성 시 사용자 가이드 범위 안의 내용만 인용해야 함.

## 본 프로젝트 데이터와의 도메인 매핑

`data/questions.json`의 6개 도메인은 위 4개 공식 도메인의 세분화/재배치 형태:

| 본 프로젝트 도메인 | 공식 도메인 대응 (추정) |
|---|---|
| `compute`, `network`, `storage`, `database` | NHN Cloud 서비스 특징 + 서비스 활용 기술 |
| `org` (조직/프로젝트) | NHN Cloud 서비스 활용 기술 |
| `common` (약관/공통) | 클라우드 개념 및 보안 + 결제 및 요금 |

콘텐츠 정비 시 출제 비율을 참고하면, 시험 대비 측면에서 본 프로젝트 데이터는 "서비스 특징/활용"(74%)에 편중된 상태. 향후 콘텐츠 추가 시 "클라우드 개념/보안", "결제/요금" 영역 보강 고려.

## 핵심 원칙 (cert-explainer 작성 시)

1. **사용자 가이드 범위 내 내용**만 사용. 그 밖의 NHN 외부 지식은 추측·창작 금지.
2. **자신 없는 영역은 보수적**으로. 단정적 표현 금지.
3. **출제 도메인 비율**을 인지하고, 도메인 컨텍스트에 맞는 깊이로 작성.
