# 문제 기준 (Question Standard)

cert-quiz 문제의 **범위·난이도·유형** 기준. 프루닝(기존 문제 정리)과 생성(보강) 모두에 적용한다.

기준 출처 3가지(합쳐서 하나의 기준):
1. **시험안내서 범위** (`docs/nhn-cloud-essentials-exam-guide.md`) — 무엇이 범위 안인가
2. **공식 샘플 8문제** (`docs/nhn-cloud-essentials-sample-questions.md`) — 난이도·유형·형식 기준선
3. **교재 연습문제 Q1–6** (CES 교재 각 섹션 끝, 비공개; 여기엔 *패턴만* 기록) — 섹션별 난이도·깊이 보정

---

## 1. 범위 (시험안내서)

| 도메인(프로젝트) | 공식 도메인 | 세부 영역 | 비율 |
|---|---|---|---|
| concept-security | 클라우드 개념 및 보안 | 클라우드 컴퓨팅 개념·특징, 책임공유 모델, 일반적인 클라우드 보안 개념 | 15% |
| service-feature | NHN Cloud 서비스 특징 | 일반적 서비스 특징(정책·리소스 제한), 각 상품의 일반적 설명 | 34% |
| service-skill | NHN Cloud 서비스 활용 기술 | 상품 활용 기술, 조직/프로젝트 개념 활용 | 40% |
| billing | 결제 및 요금 | 요금제 이해, NHN Cloud 요금 정책·크레딧 | 11% |

- **모든 문제는 공개 사용자 가이드 내용으로 뒷받침 가능해야 함**(안내서 명시). 일반 개념은 일반 공개 클라우드 지식으로 뒷받침.
- **범위 밖(제외)**: 깊은 쿠버네티스(별도 과정), 특정 제품의 깊은 운영 디테일, 시험안내서 4영역에 안 맞는 내용.

## 2. 난이도·유형 (샘플 + 연습문제)

**형식**
- 단일선택 4지선다 중심. (다중선택은 보조적으로만, 남발 금지.)
- 보기별 해설(perOption) 필수.

**인지 수준 (공식 연습문제 패턴에서 도출)**
- "다음 중 ~이 아닌 것은?" — 개념/특징 구분
- "~하는 방법/서비스로 맞는 것은?" — 목적-서비스 매칭, 용도 이해
- "반드시 필요한 것이 아닌 것은?" — 필수 vs 선택 구분
- 핵심은 **개념 이해와 서비스 구분**. 시나리오는 가볍게.

**깊이 상한 (이 시험은 입문 수준 — Associate 아님)**
- ✅ 허용: 일반 개념, 서비스 용도·목적, 필수 vs 선택, 목적↔서비스 매칭, 책임공유, 기본 특징
- ❌ 제외(너무 깊음): 숫자 한도·키 개수·발급 제한, 명령/문법, 콘솔 메뉴명·입력 라벨, 내부 메커니즘, 깊은 운영 절차/순서, 엣지 케이스

**각도 원칙**: 같은 주제라도 **얕은 각도면 범위내, 깊은 각도면 범위밖.**
예) 인스턴스 사용자 스크립트 → "필수냐 선택이냐"(O) vs "실행 시점·순서 디테일"(X).

## 3. 적용

- **프루닝**: 280문제를 위 기준으로 검토 → 범위밖/너무 깊은/유형 안 맞는 문제를 삭제 후보로. (사용자 검토 후 삭제)
- **생성(보강)**: 프루닝 후 범위 공백(특히 concept-security)을 위 난이도로 채움.
- **개수 목표 없음**: 300 등 정량 목표 폐기. 기준 충족(범위 커버 + 적정 난이도)이 목표.
